# RTMDet Top-K 진행 상황

## 완료한 작업

- RTMDet-tiny 평가 데이터 확대
  - 기존 292장 -> 고유 이미지 372장
  - 중복 이미지 79장 제거
  - 손상 이미지 없음 확인
- RTMDet-tiny 사전학습 모델로 전체 데이터 재추론
- Top-1과 Top-2 성능 비교

## 현재 결과

- 전체 Top-1 정확도: **87.63%**
- 전체 Top-2 정답 포함률: **98.39%**
- Top-2 적용 시 추가 정답 포함: **40장**

## 카테고리별 성능

| 카테고리 | Top-K | Accuracy | Precision | Recall | FPR | FNR |
|---|---:|---:|---:|---:|---:|---:|
| computer | Top-1 | 93.28% | 98.34% | 89.00% | 1.74% | 11.00% |
| book | Top-1 | 93.55% | 97.96% | 67.61% | 0.33% | 32.39% |
| computer | Top-2 | 93.28% | 90.70% | 97.50% | 11.63% | 2.50% |
| book | Top-2 | 80.38% | 49.30% | 98.59% | 23.92% | 1.41% |

Top-2는 FNR을 낮춰 정답을 놓치는 비율을 줄일 수 있지만, FPR과 오탐이 증가하는 trade-off가 있습니다. 특히 book 카테고리는 FNR이 **32.39%에서 1.41%로 감소**했지만, FPR은 **0.33%에서 23.92%로 증가**했습니다.

부트캠프 프로젝트와 공모전 참가를 병행하고 있어 학습에 사용할 수 있는 시간과 GPU 연산 크레딧이 부족한 상황입니다. 이로 인해 RTMDet 모델 크기별 학습 및 반복 실험 진행이 지연되고 있습니다.
