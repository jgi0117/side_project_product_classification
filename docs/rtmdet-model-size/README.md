# RTMDet 모델 크기별 Top-K 결과

## 완료한 작업

- COCO 사전학습 RTMDet tiny/s/m/l/x의 체크포인트와 크기별 설정을 연결하고, 동일한 이미지에서 추론했습니다.
- 이전 [RTMDet Top-K 보고서](../rtmdet-topk/README.md)와 **SHA-256 기준으로 완전히 같은 372장**을 평가했습니다. 원본 451장 중 완전 중복 79장을 제외했으며 손상 이미지는 없었습니다.
- 각 모델의 저장된 탐지 결과에서 k=1과 k=2를 모두 계산했습니다. 전체 실행의 `smoke_test=false`이고 모델 실패는 없습니다.

## 현재 결과

| 모델 | 이미지 | Top-1 정확도 | Top-2 정답 포함률 | Top-2 추가 정답 | 추론 시간 (ms/장) | 체크포인트 (MiB) |
|---|---:|---:|---:|---:|---:|---:|
| tiny | 372 | 87.63% (326) | 98.39% (366) | 40장 | 176.00 | 54.87 |
| s | 372 | 90.59% (337) | 98.66% (367) | 30장 | 251.68 | 87.21 |
| m | 372 | 93.01% (346) | **99.46% (370)** | 24장 | 481.06 | 213.91 |
| l | 372 | 92.47% (344) | 98.66% (367) | 23장 | 835.89 | 432.74 |
| x | 372 | **94.09% (350)** | 99.19% (369) | 19장 | 1346.65 | 377.26 |

괄호 안은 정답 이미지 수입니다. Top-1은 단일 예측 정확도이고 Top-2는 **최대 두 후보에 정답이 포함된 비율**입니다. Top-2 수치를 단일 분류 정확도로 해석하면 안 됩니다.

Top-1은 x가 가장 높고, Top-2 포함률은 m이 가장 높습니다. x는 m보다 Top-1 정답을 4장 더 맞혔지만, m은 x보다 Top-2에 정답을 1장 더 포함했습니다. m의 이미지당 추론 시간은 x의 약 36%이며, 체크포인트 파일은 약 43% 작습니다. 따라서 정확도만 보면 x가, 속도와 Top-2 포함률까지 함께 보면 m이 유력한 후보입니다. 이 결과만으로 최종 모델을 확정하지는 않았습니다.

| tiny | 89.00% → 97.50% | 1.74% → 11.63% | 67.61% → 98.59% | 0.33% → 23.92% |
| s | 91.50% → 98.00% | 1.16% → 15.70% | 77.46% → 98.59% | 0.00% → 20.27% |
| m | 94.50% → 99.50% | 0.00% → 13.37% | 78.87% → 98.59% | 0.00% → 17.94% |
| l | 94.50% → 99.00% | 0.58% → 12.21% | 77.46% → 97.18% | 0.00% → 18.60% |

Top-2는 모든 모델에서 정답을 더 많이 포함하지만 오탐도 늘어납니다. 예를 들어 m의 book FNR은 21.13%에서 1.41%로 낮아지는 반면 FPR은 0.00%에서 17.94%로 높아집니다. x의 Top-2 book 재현율은 100%지만 정밀도는 61.74%입니다. 후보를 실제 수락으로 사용할지에 따라 적절한 모델과 k가 달라집니다.

## 평가 조건과 한계

- 정답은 폴더당 하나의 주 라벨입니다. computer는 COCO laptop/tv, book은 COCO book에 매핑했고 나머지 폴더는 other로 평가했습니다. 사진에 대상이 여러 개 있으면 오탐이 과대 집계될 수 있습니다.
- CPU, 입력 640, 탐지 confidence 0.01, NMS IoU 0.6, 수락 임계값 0.05를 사용했습니다. 속도는 배치 1에서 워밍업 5회 후 이미지당 3회 측정한 평균이며 디스크 입출력은 제외했습니다. MiB는 모델 파라미터 수가 아니라 체크포인트 파일 크기입니다.
- 이는 **사전학습 모델의 추론 재평가**입니다. 별도 fine-tuning, 박스 mAP 측정, 세션 단위 오류율 검증은 하지 않았습니다. Top-2는 후보 집합 지표이므로 Top-1과 같은 의미의 정확도가 아닙니다.
