## 재현 정보와 해석 범위

CPU, 640 입력, 탐지 confidence 0.01, NMS IoU 0.6, 그룹 수락 임계값 0.05를 사용했습니다. 속도는 배치 1, 워밍업 5회, 이미지당 반복 3회로 측정한 탐지 처리 시간이며 디스크 입출력은 제외합니다. 체크포인트 크기는 파일 용량입니다. 같은 이미지 해시 목록을 사용했는지 확인했으며, 원본 경로는 이 공유 보고서에 넣지 않았습니다.

폴더의 단일 정답을 기준으로 하므로 한 사진에 여러 대상이 실제로 있으면 FPR이 과대 집계될 수 있습니다. 이는 사전학습 모델의 이미지 수준 평가이며 fine-tuning 결과, 객체 탐지 mAP, 세션 단위 성능이 아닙니다.
